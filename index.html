他ツールでの参照

大会情報の正本は data/brand.json、共通ライブラリは brand.js です。既存の参照APIは変更していません。

<script src="https://jbsbackgammon.github.io/common/brand.js"></script>
<script>
  JBSBrand.load().then(() => {
    const tournament = JBSBrand.getTournament('王位戦');
    const edition = JBSBrand.getEdition('王位戦');
    const textColor = JBSBrand.getTextColor(tournament.color);
    console.log(tournament.nameEn, tournament.color, edition, textColor);
  });
</script>

文字色の自動判定

共通CSSの .jbsui-auto-contrast と、brand.js の JBSBrand.applyContrast() を組み合わせ、背景色に合わせて白文字・黒文字を自動設定します。判定基準は data/brand.json を参照します。

await JBSBrand.load();
JBSBrand.applyContrast(document.querySelector('.my-banner'), '#009F40');
