ブランド管理

各JBSツールで共用する大会カラー・大会名・英語表記・文字色判定を管理します。

読み込み中

大会マスタ

順番大会名英語表記分類メインカラー表示イメージ操作

表示順の数字が小さい大会から表示します。同じ数字は指定できません。IDは連携先の互換性を守るため、作成後は変更しません。

文字色の自動判定

sRGB相対輝度がしきい値を上回る場合は「明るい背景の文字色」を使用します。初期値は 0.179 / #000000 / #FFFFFF です。

他ツールでの参照

https://jbsbackgammon.github.io/common/brand.js を読み込み、JBSBrand.load() の完了後に大会情報を取得できます。

<script src="https://jbsbackgammon.github.io/common/brand.js"></script>
<script>
  JBSBrand.load().then(() => {
    const tournament = JBSBrand.getTournament('王位戦');
    const color = tournament.color;
    const textColor = JBSBrand.getTextColor(color);
    console.log(tournament.nameEn, color, textColor);
  });
</script>

実際のデータは data/brand.json に格納されます。管理画面で編集しただけでは公開内容は変わりません。「GitHubに保存」で反映するか、JSON出力したファイルをGitHubの同じパスに上書きしてください。
